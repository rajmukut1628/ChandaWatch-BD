## Verification and remaining service setup

The feature suite covers authorization, encrypted conversations, notifications, independent approval after draft restoration, stale edits, private public summaries/feedback, content schedules/history/trash, permissions, availability, encrypted resumable uploads, clean media access, safe exports, actual encrypted backup jobs, retention, and one-use account tokens. SMTP queue delivery is tested with an injected test transport, not a live provider. Existing tests additionally cover the actual 200 MiB media boundary and encrypted restore.

SMTP delivery, real malware scanning and production infrastructure require operator-supplied services. Current scanner mode quarantines evidence. Interactive browser verification of these new screens is pending; earlier browser checks documented in `VALIDATION.md` cover only the previous release. Do not label an unconfigured integration as operational.
